NPC greeting voices for THE AMCOL WAY
=====================================

Put short MP3 clips (under 1.5 seconds, silence trimmed) in this folder with exactly these names:

  greet-male-1.mp3     "Hello!"            (male voice)
  greet-male-2.mp3     "Sawasdee krap!"    (male voice)
  greet-male-3.mp3     "Hi, cadet!"        (male voice)
  greet-female-1.mp3   "Hello!"            (female voice)
  greet-female-2.mp3   "Sawasdee ka!"      (female voice)
  greet-female-3.mp3   "Hi, cadet!"        (female voice)

File names are case-sensitive on GitHub Pages. Any clip you leave out is replaced by the
device's built-in voice saying the same words, so you can add the clips one at a time.

A greeting plays when a player talks to an NPC (press E or tap Interact). Male NPCs use the
male clips and female NPCs the female clips. Players can turn voices off in Settings.
